# Vendored River Apps UI Kit packages

These three packages are a copy of the River Apps UI Kit (private repo `idealchop/river-apps-ui-kit`):

| Package | Path | Source |
| --- | --- | --- |
| `@river-apps/tokens` | `packages/tokens` | kit `packages/tokens` @ `40c7221` (unchanged) |
| `@river-apps/icons` | `packages/icons` | kit `packages/icons` @ `40c7221` **plus the Laundry.ph icon set** (see below) |
| `@river-apps/ui` | `packages/ui` | kit `packages/ui` @ `40c7221` (unchanged) |

Kit commit: `40c7221d2663afc7fe5d01bd586db2e2085e89e5` ("feat(docs): Next.js demo with component gallery, 7 reference screens, screenshots and README").

## Local changes (to upstream)

`packages/icons` adds seven 3D icons in the kit's art style, generated by `scripts/art.py`:
`WasherIcon`, `DryerIcon`, `FoldedClothesIcon`, `LaundryBasketIcon`, `DetergentIcon`, `IronIcon`, `EWalletIcon`
(names `washer`, `dryer`, `folded`, `basket`, `detergent`, `iron`, `ewallet` for `Icon3D`). Touched files:
`scripts/art.py` (new `appl` gradient + 7 kinds), `scripts/generate.py`, `src/icons.tsx`, `src/presets.ts`, `src/index.ts`, `src/raw.ts`, `svg/*.svg`.

Components that the kit is missing live in `apps/owner/src/components/kit-extensions/` until they are upstreamed.
